# Donstra

Proof of contemporaneous agent testimony for consequential autonomous actions.

Donstra binds an authenticated agent, its evidence snapshot, its stated belief,
and one intended action into a pre-action commitment. Challenges first verify
that commitment deterministically, then use GenLayer validator consensus to
judge whether the genuine testimony was reasonable.
